# uo

魚やウーパールーパーをバケツで捕まえて、属性（✊ / ✌ / ✋）を持たせた 1vs1 のじゃんけん＋連打バトルをする Paper プラグインです。魚の個体データ（属性・種族・レベル・経験値・HP）はバケツのアイテムに保存されます。

## 必要環境

- Paper サーバー
- Java 25（このリポジトリのビルド要件）

## ビルドと導入

リポジトリのルートで実行します。

```sh
./gradlew build
```

生成された `build/libs/fishbattle-uo-<version>.jar` をサーバーの `plugins/` に配置して起動します。設定ファイルはありません。

賭け金機能を使う場合は Vault と経済プラグイン（EssentialsX など）が必要です。無くてもバトル自体は動作します。

## 捕まえ方

1. **捕獲バケツ**を作る: バケツ + コンブ（作業台、形なしレシピ）
2. **捕獲バケツ**を手に持ち、タラ・サケ・フグ・オタマジャクシ・熱帯魚・ウーパールーパーを右クリックで捕まえる
3. 捕まえた魚は個体入りのバケツになり、そのまま持ち歩ける
4. 魚入りバケツを手に持って右クリックすると、目の前の頭の高さに魚を出せる（バケツは消える）
5. 出した魚は水流に乗るように出した人を追いかけて泳ぎ、無敵で窒息しない。出した魚は飼い主が殴るとバケツに戻ってインベントリに入る（空きがないと回収できない）

普通の水入りバケツではバニラ通りにすくえます（個体データは付きません）。バトル用の個体にするには捕獲バケツを使ってください。捕獲バケツはクラフト（バケツ＋コンブ）または `/uo bucket` で入手できます。捕獲バケツで水を汲んだりまいたりすることもできません。魚を出すとバケツは空になります（捕獲バケツを使った場合も同様）。

## 属性（✊ / ✌ / ✋）

魚の属性はじゃんけんの手で表されます。属性はバトル中だけネームタグに表示されます。

| 属性 | 強い相手 |
| --- | --- |
| ✊ グー | ✌ チョキ |
| ✌ チョキ | ✋ パー |
| ✋ パー | ✊ グー |

相性は 1.3 倍 / 0.75 倍です。ラウンドごとの手選択は別に残っており、属性はダメージ相性に効きます。


すべての魚（タラ・サケ・フグ・オタマジャクシ・熱帯魚・ウーパールーパー）は捕獲時に ✊ / ✌ / ✋ からランダムで属性が決まります。

種族（タラ・サケ・フグ・オタマジャクシ・熱帯魚の模様 12 種・ウーパールーパーの亜種 5 種）ごとに **強さ・体力・テクニック** の3値を持ちます。属性相性がダメージに効きます。

## バトル（ムシキング式）

- `/uo demo` または `/uo battle demo` で村人を相手に1人でデモバトル（魚がなければ1匹支給、報酬なし、終了時に村人は消える）
- `/uo battle stop` でバトルを中断して終了（賭け金は返金）
- `/uo run` は降参扱い（相手の勝ち、賭け金は相手に渡る）
- 両者のuoの中間地点から32ブロック以上離れる、またはログアウトするとバトルは終了する
- 各ラウンド開始時に「クリックしろ！」→ 3, 2, 1 → スタート のカウントダウン
- バトルには**出している魚**が必要（魚入りバケツを右クリックして出す）。バケツのままでは戦えない
- `/uo battle [賭け金]` で近く（16ブロック以内）の全員に申し込み、`/uo battle <player> [賭け金]` で相手を指定（既定 100）
- 申し込みはチャットの `[受ける]` をクリックすると開始。クリック時にも相手との距離を確認する、相手が `/uo accept` で開始（`/uo deny` で拒否、60 秒で失効）
- 賭け金は Vault（EssentialsX）の残高から両者分を引き落とし、勝者が合計を受け取る。降参・離脱・ログアウトでは返金
- 各ラウンドは次の順で進む
  1. 両者が **3 秒間連打**（`【押せ！】` をクリック、または `/uo mash`）して気合を溜める
  2. その後、両者が同時に **✊ / ✌ / ✋** を選択。方法はどれでもよい
     - **1 / 2 / 3** キー（表示順に対応）またはチャットの絵文字クリック（`/uo gu` 等も可）で**選択**
     - 選択した手は**タイトル**に大きく表示され、**右クリックまたはスニーク（Shift）で確定**
     - 並び順は毎ラウンドランダムだが、両者に同じ順序で表示される
     - 確定しなくても **10秒で選択中の手に自動確定**（未選択ならランダム）
  3. 勝った側が攻撃。あいこの場合は気合の差が5%以上あれば差が大きい側が押し込み、威力は差に応じて軽減（差が小さいと選び直し）
- ダメージは自分の気合（攻撃力）・相手の気合（防御力）・属性相性（1.3 倍 / 0.75 倍）・レベルで決まり、HP を削り合って 0 になった方が負け
- 連打は攻守両方に効くので、溜めるほど攻撃も守りも強くなる
- `/uo run` で降参（相手の勝ち）
- 勝つと経験値が入り、一定量でレベルアップ（最大 Lv10）。レベルアップで最大 HP が増える。バトル終了時は両者全回復
- バトル終了後、両者の魚は HP 全回復する

## コマンドと権限

- `/uo` または `/uo help`: コマンド一覧
- `/uo info`: 手持ち（なければ所持品）の魚の情報
- `/uo battle <player>`: 対戦申し込み
- `/uo accept` / `/uo deny`: 申し込みの受諾 / 拒否
- `/uo gu` / `/uo choki` / `/uo pa`: 手を選ぶ
- `/uo mash`: 攻撃時に連打する
- `/uo run`: 降参
- `/uo heal`: 手持ちの魚を全回復
- `/uo bucket [player]`: 捕獲バケツを入手（player指定は管理者）
- `/uo give <player> <species> [level]`: 指定した魚を配布（管理者）。species 例: `salmon` `cod` `tadpole` `KOB` `LUCY`
- `/uo species`: 魚の種類一覧
- 権限: `uobattle.use`（既定は全員）、`uobattle.admin`（既定は OP）

属性は捕獲時に ✊ / ✌ / ✋ からランダムで決まります（全魚種）。

## データ

個体データはアイテムの PersistentDataContainer に保存されるため、追加のデータファイルはありません。
